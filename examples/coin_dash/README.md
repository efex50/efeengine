# coin_dash

A small 2D game on the built-in `SpriteRenderer`: collect coins, dodge the three patrolling enemies.

- Move: WASD or the arrow keys.
- Coin: +1 score. Enemy touch: score reset to 0 and the player goes back to the start.
- Collect every coin: a new round with more coins.
- There is no text rendering yet, so events go to the log (`[coin_dash] score 3`, `hit by enemy, score reset`,
  `round 2`) plus a status line once a second.

Run: `cargo xtask run coin_dash native` (or `./build.py run coin_dash native`).
Web: `cargo xtask build coin_dash web` / `cargo xtask serve coin_dash` (see `cargo xtask --help`; not tried yet).
`COIN_DASH_AUTOPLAY=1` makes a small bot walk to the nearest coin (a demo without a keyboard).

Assets are PNGs in `assets/`, generated by `python3 -I assets/make_assets.py` (standard library only) and embedded
with `include_bytes!`, then decoded by `Textures::add_png`. `coin_sheet.png` (4 frames) and `tiles.png` (5 tiles)
are atlases used through `Sprite::uv_min` / `uv_max`. The enemy patrol is plain Rust (no `.efa` script).
Tests: `cargo test -p coin_dash`.
